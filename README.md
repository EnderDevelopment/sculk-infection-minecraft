# Mentis Pravas Conquest

Mentis Pravas Conquest is a Minecraft plugin that simulates a sculk-like block infection using nether blocks. It allows for the spread of infected blocks through nether portal activation and commands, with configurable block conversions and immune blocks. The plugin also includes a feature to revert changes and convert biomes back to overworld variants.

## Install

1. Download the plugin JAR file from the releases section.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart the server to load the plugin.

## Use

1. **Infect Blocks**: Use the `/infect` command to infect a 5-block radius around you with sculk-like blocks.
2. **Revert Blocks**: Use the `/revert` command to revert infected blocks back to their original state.
3. **Overworldificator**: Use the `/overworldificator` command to convert infected blocks and biomes back to overworld variants.
4. **Nether Portal Activation**: When a nether portal is activated, it will create an explosion particle and infect a 5-block radius around the portal.
5. **Configuration**: Edit the `config.yml` file to specify world names, custom biomes, block conversions, immune blocks, and other settings.
